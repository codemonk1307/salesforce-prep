9. Previously asked at Salesforce, grouped by pattern

Compiled from public sources: the LeetCode "Salesforce" company tag, Glassdoor / LeetCode Discuss / Blind interview reports (2022 to 2026), and the classic "design a small class" problems that keep showing up in their practical rounds. Names are LeetCode titles so you can search them. E / M / H is LeetCode difficulty. Tick a box when you can re-derive it cold; progress is saved in this browser.

Do the ones tagged hot first. They are the repeat offenders across many reports.

Hashing and frequency maps hot
  • Two Sum E
    complement in dict, one pass. Follow-up: sorted input (two pointers), return all pairs, stream.
  • Group Anagrams M
    key = sorted string or 26-count tuple.
  • Valid Anagram / Find All Anagrams in a String E
    Counter equality; fixed window counts.
  • Top K Frequent Elements / Words M
    Counter + heap of size k, or bucket sort by frequency. Words: tie-break lexicographically with (-count, word).
  • Longest Consecutive Sequence M
    set; only expand from x when x-1 not in set.
  • Subarray Sum Equals K M hot
    prefix sum + count map. Negatives present, so no sliding window.
  • Contiguous Array / Continuous Subarray Sum M
    map 0 to -1; first index of prefix (or remainder).
  • Insert Delete GetRandom O(1) M hot
    dict of index + list swap-pop.
  • Design HashMap / HashSet E
    buckets of lists (chaining), talk about load factor and resize.
  • First Unique Character / First Unique Number in a stream E
    count map + queue (or OrderedDict) of candidates.
  • Isomorphic Strings / Word Pattern E
    bijection: two maps or set(zip) sizes.
  • Sort Characters By Frequency M
    Counter + sort by (-count) or buckets.
  • Encode and Decode Strings M
    length-prefix framing.
  • Logger Rate Limiter E hot
    message -> next allowed timestamp. Follow-up: memory cleanup, sliding window per message.
  • Design Underground System M
    two dicts: in-progress by user, totals by (start, end).
