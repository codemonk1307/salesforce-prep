The interview script (say it out loud, every problem)

  1. Restate the problem in one sentence. Confirm input/output types and an example.
  2. Constraints: N, value range, negatives, duplicates, sortedness, memory, streaming. Read N first.
  3. Brute force with its complexity, in 2 sentences. Then why it is too slow.
  4. Pattern + invariant: "contiguous with a constraint, so sliding window; invariant: window always valid".
  5. Walk one example by hand before typing.
  6. Code top-down: helper signatures first, then bodies. Name things. No single-letter variables outside loops.
  7. Test: trace the example, then empty, single, all-equal, negatives, max size. Fix silently, announce the fix.
  8. Complexity time + auxiliary space, and why. Then ask: "want the follow-up where X changes?"

2. The 30-day pattern-recognition program

Target skill: read an unfamiliar problem, name the pattern in under 60 seconds, derive the algorithm, code it clean, defend it. Non-goal: problem count.

Ground rules

  1. Every problem is served without a topic label. Classify first, code second.
  2. Before writing any code, answer the Eight Questions (section 3).
  3. Hints are released in stages, never all at once. Take "hint 1" only after 10 minutes stuck.
  4. Every mistake goes in the Error Log with a category, not a description.
  5. A problem is not done when it passes. It is done when you can re-derive it cold a week later.

3. The Eight Questions (answer before coding, every time)

  1. What are the constraints? N, value range, negatives, duplicates, sortedness.
  2. What observations does the structure give me? (sorted, bounded alphabet, tree, DAG, small K)
  3. What is the brute force?
  4. Why is brute force too slow? State the exact complexity.
  5. What pattern or data structure removes the redundant work?
  6. What invariant do I maintain?
  7. What is the time and auxiliary space complexity, and why?
  8. What breaks it? Empty, single element, all equal, negatives, overflow, cycles, duplicates, K > N.

Python pitfalls that cost interviews
  • [[0]*m]*n creates n references to the same row. Use a comprehension.
  • Mutable default args: def f(x, memo={}) is shared across calls. Use None and create inside.
  • Recursion depth: default 1000. A 10^5-node linked list or skewed tree recursion crashes. Set the limit or go iterative.
  • @cache on a method holds self in the cache key; fine in interviews, but list args must become tuples.
  • Integer division on negatives floors: -1 // 2 == -1. Use int(a / b) to truncate toward zero if the problem says so.
  • Modifying a list while iterating over it skips elements. Iterate over a copy or build a new list.
  • heapq compares whole tuples: if two priorities tie and the payload is not comparable (dict, custom object) you get a TypeError. Add a counter as the second element.
  • dict.keys() view changes size during iteration -> RuntimeError. Snapshot with list(d).
  • is vs ==: use is None, == for values.
  • Strings are immutable: build a list of chars, join at the end.
  • sorted returns a new list; .sort() returns None. x = arr.sort() is a classic slip.
  • range excludes the stop. range(n-1, -1, -1) for reverse to 0.
  • Deep copy: copy.deepcopy for nested; arr[:] or list(arr) is shallow.
  • Float precision: compare with tolerance, or work in integers (multiply out).
  • Closures capture variables, not values: lambdas in a loop all see the final i. Use default arg lambda i=i:.

Linked list: node, reverse, fast/slow, merge, dummy head very common
class ListNode:
    def __init__(self, val=0, next=None):
        self.val, self.next = val, next

def reverse(head):
    prev, cur = None, head
    while cur:
        cur.next, prev, cur = prev, cur, cur.next     # one-line rotate
    return prev

def reverse_between(head, left, right):           # reverse positions left..right (1-indexed)
    dummy = ListNode(0, head); pre = dummy
    for _ in range(left - 1): pre = pre.next
    cur = pre.next
    for _ in range(right - left):                 # head-insertion trick
        nxt = cur.next
        cur.next = nxt.next
        nxt.next = pre.next
        pre.next = nxt
    return dummy.next

def middle(head):                                 # second middle for even length
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
    return slow

def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast: return True
    return False

def cycle_start(head):                            # Floyd: reset one pointer to head
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:
            slow = head
            while slow is not fast: slow, fast = slow.next, fast.next
            return slow
    return None

def kth_from_end(head, k):
    lead = follow = head
    for _ in range(k): lead = lead.next
    while lead: lead, follow = lead.next, follow.next
    return follow

def merge_sorted(a, b):
    dummy = tail = ListNode()
    while a and b:
        if a.val <= b.val: tail.next, a = a, a.next
        else: tail.next, b = b, b.next
        tail = tail.next
    tail.next = a or b
    return dummy.next

def remove_nth_from_end(head, n):
    dummy = ListNode(0, head); lead = follow = dummy
    for _ in range(n + 1): lead = lead.next
    while lead: lead, follow = lead.next, follow.next

class DSU:
    def __init__(self, n):
        self.parent = list(range(n)); self.size = [1] * n; self.components = n
    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]     # path halving
            x = self.parent[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb: return False                          # already connected (cycle!)
        if self.size[ra] < self.size[rb]: ra, rb = rb, ra
        self.parent[rb] = ra; self.size[ra] += self.size[rb]
        self.components -= 1
        return True
    def connected(self, a, b): return self.find(a) == self.find(b)

class SegTree:                                     # iterative, min/max/sum by changing op
    def __init__(self, arr, op=min, identity=float('inf')):
        self.n = len(arr); self.op = op; self.id = identity
        self.t = [identity] * (2 * self.n)
        self.t[self.n:] = arr
        for i in range(self.n - 1, 0, -1): self.t[i] = op(self.t[2*i], self.t[2*i+1])
    def update(self, i, val):

        while i > 1:

        res = self.id; l += self.n; r += self.n

            if r & 1: r -= 1; res = self.op(res, self.t[r])

# ---- Kahn's algorithm (BFS on indegree), the one to write by default ----
def topo_kahn(n, g):                              # g: adjacency list u -> [v], edge u before v
    indeg = [0] * n
    for u in range(n):
        for v in g[u]: indeg[v] += 1
    q = deque(u for u in range(n) if indeg[u] == 0)
    order = []
    while q:
        u = q.popleft(); order.append(u)
        for v in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0: q.append(v)
    return order if len(order) == n else []       # [] => cycle exists
# Invariant to say: a node enters the queue only when every prerequisite has already been output.
# Time O(V + E), space O(V). Course Schedule I: return len(order) == n. Course Schedule II: return order.

# ---- DFS post-order version (reverse of finishing order) with cycle detection via colors ----
def topo_dfs(n, g):
    WHITE, GRAY, BLACK = 0, 1, 2
    color = [WHITE] * n; out = []
    def dfs(u):
        color[u] = GRAY
        for v in g[u]:
            if color[v] == GRAY: return False      # back edge => cycle
            if color[v] == WHITE and not dfs(v): return False
        color[u] = BLACK; out.append(u)           # post-order
        return True
    for u in range(n):
        if color[u] == WHITE and not dfs(u): return []
    return out[::-1]                              # reverse post-order is a topological order

# ---- iterative DFS version (deep graphs, no recursion limit worries) ----
def topo_dfs_iter(n, g):
    color = [0] * n; out = []
    for s in range(n):
        if color[s]: continue
        st = [(s, 0)]; color[s] = 1                # (node, next child index)
        while st:
            u, i = st[-1]
            if i < len(g[u]):
                st[-1] = (u, i + 1); v = g[u][i]
                if color[v] == 1: return []       # cycle
                if color[v] == 0: color[v] = 1; st.append((v, 0))
            else:
                color[u] = 2; out.append(u); st.pop()
    return out[::-1]

The two-minute explanation you should be able to give

  1. Compute indegree of every node: how many things must come before it.
  2. Everything with indegree 0 has no prerequisites, so it can go first: put it in the queue.
  3. Pop a node, output it, and "remove" it: decrement indegree of every neighbour. Any neighbour that hits 0 is now free: enqueue.
  4. If you output all V nodes, that is a valid order. If not, the leftovers all sit on a cycle, because each is waiting on another leftover.
  5. O(V + E): every node enqueued once, every edge relaxed once.

Undirected graphs have no topological order. If they give you an undirected "dependency" problem, it is Union-Find or tree traversal, not topo sort.

def fixed_window(nums, k):                         # e.g. max sum of any k consecutive

def at_most_k_distinct(s, k):                      # count of substrings with <= k distinct
    if k < 0: return 0

Problem: uppercase string, replace every char by the letter K positions counterclockwise (backward) on a wheel A..Z that wraps. Length and K up to 10^5.

def decrypt(encrypted: str, k: int) -> str:
    k %= 26                                                    # the wheel has 26 stops
    return ''.join(chr((ord(c) - 65 - k) % 26 + 65) for c in encrypted)

OA-2 · Parade: every "01" becomes "10" each second, how many seconds until stable O(n), no simulation

Problem: binary string, 0 = red, 1 = blue. Each second all "01" substrings flip to "10" simultaneously. Return the number of seconds until no "01" remains. Example 0010101 → 4 seconds. (LeetCode 2380 "Time Needed to Rearrange a Binary String".)

Insight: simulation is O(n^2) and times out at 10^5. Think about each '1' individually: it has to move left past every '0' that is before it, one step per second, so on its own it needs zeros_before seconds. But it cannot overtake the '1' ahead of it: if the previous '1' finishes at time t, this one finishes no earlier than t + 1. So t = max(t + 1, zeros_before), and the answer is the finishing time of the last '1'. A '1' with no zeros before it never moves.
def seconds_until_stable(color: str) -> int:
    zeros = t = 0
    for c in color:
        if c == '0':
            zeros += 1
        elif zeros:                        # a '1' that has zeros to cross
            t = max(t + 1, zeros)
    return t

# 0010101: zeros=2 at first '1' -> t=2; zeros=3 -> t=max(3,3)=3; zeros=4 -> t=max(4,4)=4.  Answer 4.
# Edges: all zeros or all ones -> 0; "1110" -> 0; "0111" -> 3 (1 sec each, chained by the +1 rule).

def frequency_sort(s: str) -> str:
    cnt = Counter(s)
    return ''.join(ch * c for ch, c in cnt.most_common())   # most_common sorts by count desc

def frequency_sort_stable(s: str) -> str:

R2-1 · Remove duplicate letters, each letter once, lexicographically smallest result monotonic stack O(n)

Problem: "bcabc" → "abc"; "cbacdcbc" → "acdb". Keep relative order, every distinct letter exactly once, smallest possible string. (LeetCode 316 / 1081.)

Insight: this is a greedy monotonic stack with one extra permission check. Build the answer left to right in a stack. When a new char c arrives that is smaller than the stack top, you would like to pop the top to make the prefix smaller, but you may only pop it if it appears again later (otherwise you lose it forever). So keep last[ch] = last index of each char, and a used set so a char already in the stack is skipped. Each char is pushed and popped at most once: O(n).
def remove_duplicate_letters(s: str) -> str:
    last = {ch: i for i, ch in enumerate(s)}      # last occurrence of each char
    st, used = [], set()
    for i, ch in enumerate(s):
        if ch in used: continue                    # already placed, and it is in its best spot
        while st and st[-1] > ch and last[st[-1]] > i:   # top is bigger AND will appear again
            used.discard(st.pop())
        st.append(ch); used.add(ch)
    return ''.join(st)

# "cbacdcbc": c | b<c and c appears later -> pop c, push b | a<b, b later -> pop b, push a | c | d | c used, skip
#            | b<d but d never again -> keep d, push b | c used. Result "acdb".
# Say: O(n) time, O(k) space with k distinct chars. Invariant: the stack is the lexicographically smallest
# valid answer for the prefix seen so far, given what still lies ahead.
# Probes: why not just sort (order must be preserved), "Remove K Digits" (same stack without the last[] check),
# "Smallest Subsequence of Distinct Characters" (identical problem).
R2-2 · Sum of minimums of every contiguous subarray monotonic stack + contribution, O(n)

Problem: [3,1,2,4] → subarrays [3],[1],[2],[4],[3,1],[1,2],[2,4],[3,1,2],[1,2,4],[3,1,2,4] with mins 3,1,2,4,1,1,2,1,1,1 = 17. n up to 3*10^4, answer mod 10^9+7. (LeetCode 907.)

Insight: flip the question. Instead of "what is the min of each subarray" (O(n^2) subarrays), ask "for how many subarrays is arr[i] the minimum?" That is left[i] * right[i], where left[i] = number of ways to extend leftward before hitting a smaller element, right[i] = same to the right. Answer = sum arr[i] * left[i] * right[i]. Previous-smaller and next-smaller come from a monotonic stack in O(n). Duplicates: use strict on one side and non-strict on the other, so a subarray with two equal minimums is counted once.
def sum_subarray_mins(arr: list[int]) -> int:
    MOD = 10**9 + 7; n = len(arr)
    left = [0] * n; right = [0] * n; st = []
    for i in range(n):                             # previous strictly smaller
        while st and arr[st[-1]] > arr[i]: st.pop()
        left[i] = i - (st[-1] if st else -1)
        st.append(i)
    st = []
    for i in range(n - 1, -1, -1):                 # next smaller OR EQUAL (non-strict) to avoid double count
        while st and arr[st[-1]] >= arr[i]: st.pop()
        right[i] = (st[-1] if st else n) - i
        st.append(i)
    return sum(a * l * r for a, l, r in zip(arr, left, right)) % MOD

# [3,1,2,4]: left [1,2,1,1], right [1,3,2,1] -> 3*1*1 + 1*2*3 + 2*1*2 + 4*1*1 = 3+6+4+4 = 17.
# Say: O(n) time, O(n) space. Probes: duplicates (the strict/non-strict pair), sum of subarray MAXIMUMS
# (flip the comparisons), sum of (max - min) over all subarrays (do both, subtract).
Follow-up they asked: sum of ALL subarray sums. Same contribution idea with no stack at all: arr[i] appears in (i + 1) * (n - i) subarrays (choose any start <= i, any end >= i).
def sum_all_subarray_sums(arr: list[int]) -> int:
    n = len(arr)
    return sum(x * (i + 1) * (n - i) for i, x in enumerate(arr))
# [1,2,3] -> 1*1*3 + 2*2*2 + 3*3*1 = 3 + 8 + 3 = 20. Check: 1+2+3+3+5+6 = 20. O(n), O(1).
R3-1 · Longest palindrome you can build from two strings interval DP O((m+n)^2)

Problem as asked: two strings, build the maximum-length palindrome and return its length. Clarify which version before coding; both are below.

Version A (the LeetCode-hard one, 1771): pick a non-empty subsequence from word1 and a non-empty subsequence from word2, concatenate, must be a palindrome. Trick: concatenate s = word1 + word2 and run the standard longest-palindromic-subsequence interval DP, but only accept dp[i][j] as an answer when s[i] == s[j] with i inside word1 and j inside word2. That single check enforces "uses both strings" because the outermost matched pair straddles the boundary.
def longest_palindrome_two_strings(word1: str, word2: str) -> int:
    s = word1 + word2; n = len(s); m = len(word1); best = 0
    dp = [[0] * n for _ in range(n)]           # dp[i][j] = LPS length inside s[i..j]
    for i in range(n - 1, -1, -1):
        dp[i][i] = 1
        for j in range(i + 1, n):
            if s[i] == s[j]:
                dp[i][j] = dp[i + 1][j - 1] + 2
                if i < m <= j:                 # outer pair straddles word1 | word2
                    best = max(best, dp[i][j])
            else:
                dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
    return best                                # 0 if impossible

# "cacb", "cbba" -> 5 ("abcba"). Space can drop to O(n) with two rows if asked.
# Say: states (i, j) = O(n^2), O(1) transition -> O(n^2) time and space.
Version B (the easy one): you may rearrange the characters of both strings freely. Then it is just counting: every pair of a letter contributes 2, plus one odd letter in the middle.
def longest_palindrome_from_chars(a: str, b: str) -> int:
    cnt = Counter(a + b); length = 0; odd = False
    for c in cnt.values():
        length += c // 2 * 2
        odd = odd or c % 2 == 1
    return length + odd                       # O(m + n)
R3-2 · Directed graph with cycles: distance of every node to the nearest node on a cycle O(V + E)

Problem: directed graph that contains cycles. For each node return its distance (following edges) to the closest node that is part of a cycle. Cycle nodes get 0.

Two-step insight: (1) find exactly which nodes lie on a cycle; (2) the distance "from u to the nearest cycle node along edges" is a shortest path into a set of targets, so run one multi-source BFS from all cycle nodes on the reversed graph. Reversing turns "u reaches target" into "target reaches u", and BFS from many sources at distance 0 gives the nearest one for free.
Most likely version (each node has exactly one outgoing edge, a "functional graph", like LeetCode 2360): peel nodes with in-degree 0 repeatedly (Kahn's). Whatever survives is on a cycle. Then every peeled node's distance is 1 + distance of the node it points to.
def dist_to_cycle_functional(nxt: list[int]) -> list[int]:
    # nxt[i] = the single node i points to (every node has one out-edge)
    n = len(nxt); indeg = [0] * n
    for v in nxt: indeg[v] += 1
    q = deque(i for i in range(n) if indeg[i] == 0); on_cycle = [True] * n
    while q:                                   # peel: anything peeled is not on a cycle
        u = q.popleft(); on_cycle[u] = False
        indeg[nxt[u]] -= 1
        if indeg[nxt[u]] == 0: q.append(nxt[u])
    dist = [0 if on_cycle[i] else -1 for i in range(n)]
    for i in range(n):                         # walk each tree node down to a known distance
        if dist[i] != -1: continue
        path, u = [], i
        while dist[u] == -1: path.append(u); u = nxt[u]
        d = dist[u]
        for node in reversed(path): d += 1; dist[node] = d
    return dist
# O(n): every node is peeled once and assigned once.
General directed graph (any out-degree): cycle nodes = members of a strongly connected component of size > 1, or a node with a self-loop. Tarjan gives SCCs in O(V + E). Then reversed multi-source BFS. Nodes that cannot reach any cycle get -1.
def dist_to_nearest_cycle_node(n: int, edges: list[tuple[int, int]]) -> list[int]:
    g = [[] for _ in range(n)]; rg = [[] for _ in range(n)]
    for u, v in edges: g[u].append(v); rg[v].append(u)

    # 1) Tarjan SCC -> which nodes are on a cycle
    idx = [-1] * n; low = [0] * n; on_stack = [False] * n; st = []; t = 0
    on_cycle = [False] * n
    def dfs(u):
        nonlocal t
        idx[u] = low[u] = t; t += 1; st.append(u); on_stack[u] = True
        for v in g[u]:
            if idx[v] == -1: dfs(v); low[u] = min(low[u], low[v])
            elif on_stack[v]: low[u] = min(low[u], idx[v])
        if low[u] == idx[u]:                   # u is the root of an SCC
            comp = []
            while True:
                v = st.pop(); on_stack[v] = False; comp.append(v)
                if v == u: break
            if len(comp) > 1 or u in g[u]:     # real cycle (or self-loop)
                for v in comp: on_cycle[v] = True
    for u in range(n):
        if idx[u] == -1: dfs(u)

    # 2) multi-source BFS from cycle nodes over REVERSED edges
    dist = [-1] * n; q = deque()
    for u in range(n):
        if on_cycle[u]: dist[u] = 0; q.append(u)
    while q:
        v = q.popleft()
        for u in rg[v]:                        # u -> v in the original graph
            if dist[u] == -1: dist[u] = dist[v] + 1; q.append(u)
    return dist
# O(V + E) time and space. Set sys.setrecursionlimit for Tarjan, or mention the iterative version.
# Interviewer probes: why reversed (direction of "reach"), why SCC and not "survivors of Kahn's"
# (survivors include nodes DOWNSTREAM of a cycle in a general graph), what about self-loops.

R4-1 · Equalize task durations with removals, minimum operations sort + prefix sums, O(n log n)

Problem: duration[i] per task. One operation: pick a task, reduce by 1; at 0 it is removed. Reach a state where all remaining tasks are equal, in minimum operations. [1, 2, 6, 3] → 6.

Exchange argument (say this, it is the whole interview): any final state is "every survivor equals some t". A task with duration x < t cannot be raised, so it must be removed, cost x. A task with x >= t should be kept, not removed, because x - t < x. So cost(t) = sum of values below t + sum of (x - t) for values at or above t. cost(t) is piecewise linear in t with breakpoints at the array values, so the minimum is at one of the values. Sort, prefix sums, try every value as t in O(1) each.
def min_ops_to_equalize(duration: list[int]) -> int:
    d = sorted(duration); n = len(d)
    pre = [0]
    for x in d: pre.append(pre[-1] + x)                  # pre[i] = sum of d[:i]
    best = pre[n]                                        # remove everything (never better than keeping the max)
    for i in range(n):                                   # target t = d[i]; remove d[:i], reduce d[i:] to t
        t = d[i]
        removed = pre[i]
        reduced = (pre[n] - pre[i]) - t * (n - i)
        best = min(best, removed + reduced)
    return best

# [1,2,6,3] -> sorted [1,2,3,6]: t=1: 8, t=2: 1+5=6, t=3: 3+3=6, t=6: 6 -> 6.
# O(n log n) for the sort, O(n) after. O(n) space (prefix), O(1) if you accumulate while scanning.
# Follow-up they like: "duplicates?" (fine, equal t evaluated twice); "can we increase too?" (then it is median, not this).
R4-2 · Construct a binary tree from inorder + level-order traversals O(n^2) worst, O(n log n) balanced
Insight: the first element of any level-order sequence is that subtree's root. Its position in inorder splits left and right subtrees. The level-order of the left subtree is simply the current level-order filtered to the nodes that sit left of the root in inorder, keeping their relative order (level order of a subtree is a subsequence of the parent's level order). Recurse. An inorder index map makes the filter a comparison instead of a search.
def build_tree(inorder: list[int], levelorder: list[int]):
    pos = {v: i for i, v in enumerate(inorder)}          # values assumed unique
    def build(level):                                    # level = level-order of this subtree
        if not level: return None
        root = TreeNode(level[0]); m = pos[level[0]]
        root.left  = build([v for v in level if pos[v] < m])
        root.right = build([v for v in level if pos[v] > m])
        return root
    return build(levelorder)

11. LLD and system design, the compressed version

Salesforce asks LLD at MTS and mixes HLD in at SMTS. The scoring is the same: clarify, enumerate entities, define the API, show one flow end to end, then discuss trade-offs and failure modes. Do not draw before you have asked three questions.

The 45-minute script

  1. Requirements (5 min): functional (3 to 5 bullets), non-functional (scale, latency, consistency, availability), out of scope. Say numbers: users, QPS, data size, read/write ratio.
  2. Entities and API (10 min): nouns become classes/tables, verbs become methods/endpoints. Write signatures.
  3. Core flow (10 min): one happy path end to end with the data structures involved.
  4. Deep dive (10 min): the hardest part: concurrency, eviction, scheduling, consistency.
  5. Trade-offs and failure (5 min): what breaks at 10x, what you would monitor, what you would change.

import time, itertools

class VehicleType(Enum): MOTORBIKE = 1; CAR = 2; TRUCK = 3
class SpotType(Enum): SMALL = 1; MEDIUM = 2; LARGE = 3

FITS = {VehicleType.MOTORBIKE: (SpotType.SMALL, SpotType.MEDIUM, SpotType.LARGE),
        VehicleType.CAR: (SpotType.MEDIUM, SpotType.LARGE),
        VehicleType.TRUCK: (SpotType.LARGE,)}

class Vehicle:
    def __init__(self, plate, vtype): self.plate, self.vtype = plate, vtype

class Spot:
    def __init__(self, spot_id, stype, floor): self.id, self.stype, self.floor = spot_id, stype, floor; self.vehicle = None
    def is_free(self): return self.vehicle is None

class Ticket:
    _ids = itertools.count(1)
    def __init__(self, vehicle, spot): self.id = next(self._ids); self.vehicle, self.spot = vehicle, spot; self.entry = time.time(); self.exit = None

class PricingStrategy(ABC):
    @abstractmethod
    def fee(self, ticket) -> float: ...
class HourlyPricing(PricingStrategy):
    RATE = {SpotType.SMALL: 10, SpotType.MEDIUM: 20, SpotType.LARGE: 40}
    def fee(self, t): hours = max(1, math.ceil((t.exit - t.entry) / 3600)); return hours * self.RATE[t.spot.stype]

class ParkingLot:                                  # Singleton in a real codebase; keep free spots per type in a heap for "nearest"
    def __init__(self, pricing): self.free = defaultdict(list); self.tickets = {}; self.pricing = pricing; self.lock = threading.Lock()
    def add_spot(self, spot): heapq.heappush(self.free[spot.stype], (spot.floor, spot.id, spot))
    def park(self, vehicle):
        with self.lock:
            for st in FITS[vehicle.vtype]:
                if self.free[st]:
                    _, _, spot = heapq.heappop(self.free[st]); spot.vehicle = vehicle
                    t = Ticket(vehicle, spot); self.tickets[t.id] = t; return t
            raise RuntimeError('lot full')
    def unpark(self, ticket_id):
        with self.lock:
            t = self.tickets.pop(ticket_id); t.exit = time.time(); spot = t.spot; spot.vehicle = None
            heapq.heappush(self.free[spot.stype], (spot.floor, spot.id, spot))
            return self.pricing.fee(t)

class BoundedBlockingQueue:                        # producer / consumer with Condition
    def __init__(self, cap): self.q = deque(); self.cap = cap; self.cv = threading.Condition()
    def put(self, x):
        with self.cv:
            while len(self.q) == self.cap: self.cv.wait()
            self.q.append(x); self.cv.notify_all()
    def get(self):
        with self.cv:
            while not self.q: self.cv.wait()
            x = self.q.popleft(); self.cv.notify_all(); return x
